Responsive Design with Media Queries

This page adapts to desktop, tablet and mobile screens. Resize the browser window and watch the layout, the menu and the badge in the header change.

Desktop

1025px and above

Full horizontal menu, 4-column gallery, 3 course cards in a row.

Tablet

601px to 1024px

Centred menu, 3 or 2 gallery columns, stacked form labels.

Mobile

600px and below

Hamburger menu, single-column layout, full-width buttons.

5. Sticky

Sticky heading

Scroll inside this box. The heading above sticks to the top edge once you reach it.

Sticky works like relative until a scroll threshold is reached, then it behaves like fixed inside its scroll container.

The main navigation bar and the trainer table header use the same technique.
