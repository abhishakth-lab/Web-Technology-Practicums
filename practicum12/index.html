    DOM Methods Used on This Page

    • getElementById() and querySelector(): find the inputs, buttons and lists.
    • createElement() and appendChild(): build new plan items and course cards.
    • textContent and innerHTML: show typed text safely and reset containers.
    • setAttribute(): set data-*, aria-* and hidden attributes.
    • remove(): delete plan items, course cards and dropdown options.
    • addEventListener(): react to clicks, typing and the Enter key.

    Live Training Data (API)

    This section retrieves corporate-training data from a REST endpoint using fetch() with async / await. The JSON response is turned into table rows and summary cards by JavaScript. A loading indicator is shown while the request runs, and errors are handled with try, catch and finally.

    Fetch API Methods Used in This Section

    • fetch(url): sends an HTTP GET request to the endpoint and returns a Promise.
    • async and await: wait for the response without freezing the page.
    • response.ok and response.json(): check the status code, then parse the JSON body.
    • try, catch and finally: handle failures, then always hide the loader.
    • createElement(), appendChild() and textContent: build the table and cards from the data.

    4. Fixed

    position: fixed; bottom: 1.25rem; left: 1.25rem; Positioned relative to the browser window.

    5. Sticky

    Sticky heading

    Scroll inside this box. The heading above sticks to the top edge once you reach it.

    Sticky works like relative until a scroll threshold is reached, then it behaves like fixed inside its scroll container.

    The main navigation bar and the trainer table header use the same technique.

    Industry uses: sticky menus, table headers, section titles and sidebars.

    Keep scrolling to see the heading stay in place.

    position: sticky; top: 0; Switches from relative to fixed at the threshold.
